## Что было сделано

На страницу из ЛР №3 добавлен скрипт `script.js`, который реализует:

### 1. Ввод / вывод

- `prompt` — запрос имени пользователя.
- `alert` — приветствие и вывод итоговой суммы калорий.
- `console.log` — вывод дополнительной информации в консоль браузера.

### 2. Условные конструкции и циклы

- `if` — проверка условий (низкокалорийные блюда, сумма > 3000).
- `for` — перебор массива калорий.

### 3. Функции

- `findMax(array)` — поиск максимального значения в массиве.
- `sumArray(array)` — подсчёт суммы элементов массива.
- `filterArray(array, minValue)` — фильтрация массива по условию.

### Вариант 8

- Массив из 7 чисел — калорийность блюд в ккал.
- Фильтрация — блюда > 600 ккал (высококалорийные).
- Цикл — подсчёт низкокалорийных блюд (≤ 300 ккал) и их доли.
- **alert:** «Суммарная калорийность — X ккал, из них Y ккал — в высококалорийных блюдах».
- **console.log:** доля низкокалорийных блюд и их количество.
- **Дополнительно:** если сумма > 3000 ккал — вывод в консоль «Такой рацион лучше распределить на 2 дня».
